# 📊 Customer Behavior Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Customer Behavior Analysis Dashboard** built using **Power BI**. The dashboard analyzes customer purchasing patterns, demographics, spending habits, and engagement trends to uncover actionable insights that support data-driven marketing and business strategies.

By transforming raw customer data into interactive visualizations, the dashboard helps businesses understand customer preferences, improve retention, and optimize sales performance.

---

## 🎯 Business Objectives

* Analyze customer purchasing behavior and spending patterns.
* Identify high-value customer segments.
* Evaluate customer engagement across different demographics.
* Discover factors influencing purchasing decisions.
* Enable interactive analysis for business stakeholders.
